如何添加新的照片和视频
========================

小提示：顶部导航的「首页 / 相册 / 影像 / 文件 / 关于」
会切换到各自独立的界面，网址末尾的 #albums、#gallery 等可以直接收藏。

【方式一：网页上传（推荐）】

1. 在项目根目录打开终端，运行：
   node server.js

2. 浏览器会自动打开网站（网址类似 http://localhost:5173/）

3. 点击右上角「上传」，选择或拖入照片/视频，先预览确认，
   再点「确认上传」。照片和视频会自动分类到照片区/视频区，
   默认保存到「我的上传」相册（可以在弹窗里改相册名，
   或点「新建相册」输入一个新的相册名）。

4. 删除照片/视频：点击缩略图右上角的 ×，
   或者打开大图后点右上角「删除」。确认后会同时删掉
   网站上的记录和 media 文件夹里的文件（无法恢复）。

5. 关闭终端或按 Ctrl+C 停止服务器后，网站仍可双击网页浏览，
   只是不能再上传和删除。

【方式二：手动放文件 + 扫描】

1. 照片：放进 media/photos/相册名/ 文件夹
   例如 media/photos/2026 生日/xxx.jpg
   文件夹名就是相册名，支持多级，例如 media/photos/旅行/四川/

2. 视频：放进 media/videos/相册名/ 文件夹
   推荐 .mp4 格式，浏览器兼容性最好

3. 其他文件（PDF、Word、压缩包）：放进 files/ 文件夹

4. 然后运行：
   node tools/scan-media.js

   刷新网页，新内容就会出现。

提示：
- 文件名会用作文档标题，建议起个清楚的名字
- 照片和视频按文件修改时间归入对应月份
- 这个示例文件可以随时删除
